# 🎯 우파루 오딧세이 크로스 기댓값 계산기

650만 건 이상의 우파루 크로스 데이터를 기반으로  
최적의 크로스 조합과 기대값을 계산하는 분석 시스템입니다.

대용량 데이터를 처리하며  
성능 중심으로 설계된 분석 엔진입니다.

---

## 📌 프로젝트 배경

게임 내 복잡한 크로스 조합의 기대값을 효율적으로 계산하기 위해 개발했습니다.
반복 계산 비용을 줄이기 위해 사전 계산 기반 구조를 설계했습니다.

---

## ⚙️ 기술 스택

- Kotlin
- Spring Boot
- PostgreSQL (운영용)
- H2 (개발용)
- JdbcTemplate
- AWS (Free Tier)
- Gradle

---

## 🔄 데이터 흐름

CSV 기반 데이터 적재 → 크로스 결과 계산 → cross-rate 저장 → 기대값 사전 계산 → 조회 최적화

---

## 🚀 핵심 기능

- 약 650만 건 규모 CSV 데이터 파싱 및 DB 적재 처리
- 우파루 크로스 결과 분석
- cross-rate 기반 기대값 모델링
- 대용량 데이터 처리 성능 확보를 위해 JdbcTemplate 기반 배치 처리 구현

---

## 🏗️ 핵심 설계

- 사전 계산 기반 구조
- Runtime 계산 최소화
- 조회 최적화 중심 설계
- 관리자 기반 데이터 재구축
