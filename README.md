# 🐾 우파루 오딧세이 크로스 기댓값 계산기

> **750만 건 이상의 크로스 데이터를 분석하여 최적의 조합을 추천하는 백엔드 분석 시스템**

우파루 오딧세이의 크로스 데이터를 수집·분석하여 목표 우파루를 가장 효율적으로 획득할 수 있는 조합을 추천하는 서비스입니다.

대용량 데이터 환경에서 조회 시 반복적으로 발생하는 계산 비용을 줄이기 위해 **사전 계산(Precomputation)** 구조를 설계했으며,<br>
**Batch Insert**, **조회 최적화**, **메모리 캐시**를 적용하여 데이터 처리와 조회 성능을 개선했습니다.

# ❓ 해결하고자 한 문제

크로스 조합은 경우의 수가 많아 요청마다 기댓값을 계산하는 방식은 동일한 계산이 반복되고,<br>
데이터 규모가 증가할수록 조회 비용도 함께 증가하는 문제가 있었습니다.

이 프로젝트는 **"조회 시 계산하지 않는다."** 를 목표로 시스템을 설계했습니다.

모든 조합의 기댓값을 미리 계산하여 저장하고, API는 계산 대신 조회만 수행하도록 구조를 변경했습니다.

# 🏗 핵심 설계

## 1. 사전 계산(Precomputation)

반복적으로 수행되는 기댓값 계산을 Runtime에서 수행하지 않고,<br>
관리자 재구축 시 모든 조합을 미리 계산하여 `cross_expected_time` 테이블에 저장하도록 설계했습니다.

조회 시에는 사전 계산된 데이터를 활용하여 계산 없이 결과를 반환합니다.

---

## 2. 대용량 데이터 적재

약 750만 건의 CSV 데이터를 적재하기 위해 `JdbcTemplate`의 Batch Insert를 적용했습니다.

또한 대량 INSERT 과정에서 발생하는 Index 갱신 비용을 줄이기 위해 다음 순서로 Import를 수행하도록 설계했습니다.

```text
Index 제거
      │
      ▼
Batch Import
      │
      ▼
Index 재생성
```

이를 통해 대량 데이터 적재 시 불필요한 오버헤드를 줄였습니다.

---

## 3. 조회 최적화

사전 계산된 데이터를 기반으로 조회가 이루어지도록 구성했습니다.

* Expected Time 전용 테이블 분리
* JOIN 기반 조회
* LIMIT를 활용한 결과 제한
* GROUP BY / HAVING을 활용한 다중 목표 조합 검색

---

## 4. 메모리 캐시

CSV 데이터는 이름 기반이지만 데이터베이스는 ID 기반으로 관리됩니다.

Import 및 조회 과정에서 반복적인 이름 조회를 방지하기 위해 우파루 정보를 메모리에 캐싱하여 Name ↔ ID 변환에 활용했습니다.

# 📦 데이터 수집

Playwright 기반 크롤러를 직접 구현하여 크로스 데이터를 수집했습니다.

장시간 실행되는 크롤링을 고려하여 다음 기능을 적용했습니다.

# 🚨 트러블슈팅

## Oracle Cloud Always Free 환경 메모리 부족

Oracle Cloud Always Free(1GB RAM) 환경에서 PostgreSQL과 Spring Boot를 함께 운영하는 과정에서<br>
메모리 부족으로 애플리케이션이 종료되는 문제가 발생했습니다.

원인을 분석한 결과 `dnf-makecache.timer` 프로세스가 메모리를 점유하면서 OOM이 발생하는 것을 확인했습니다.

다음과 같은 방법으로 문제를 해결했습니다.

* Swap 메모리 구성
* `dnf-makecache.timer` 비활성화
* Batch Insert 및 Chunk 단위 처리 적용
* Runtime 계산 제거를 통한 서버 부하 감소

이를 통해 약 750만 건 규모의 데이터를 안정적으로 운영할 수 있는 환경을 구축했습니다.

# 💭 프로젝트를 마치며

이 프로젝트는 단순히 추천 기능을 구현하는 것이 아니라, **언제 계산하고 언제 저장하며 언제 조회할 것인가**를 고민하며 설계한 프로젝트였습니다.

특히 Runtime에서 반복되는 계산을 사전 계산 구조로 변경하면서 조회 성능뿐 아니라 시스템 구조 자체를 단순화할 수 있었습니다.

또한 대용량 데이터를 처리하는 과정에서 Batch 처리, Index 관리, 메모리 캐시와 같은 설계가 실제 성능과 운영에 미치는 영향을 경험할 수 있었습니다.
